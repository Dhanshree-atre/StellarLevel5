# Demo script

Use the deployed application and a real Lace Preprod wallet. Never stage a fake transaction.

1. Open the live URL and introduce the problem: useful claims often require unnecessary personal data.
2. Show the Veilmark proof screen and explain the result/context distinction.
3. Open Lace and connect on Midnight Preprod.
4. Show the connected wallet state without exposing a full address on recording.
5. Submit the main proof action.
6. Show the pending state, then the confirmed receipt and explorer link.
7. Explain which result is public and which input remains private.
8. Open the feedback form and explain how user feedback drives the next release.

Record the final video URL in README only after upload and verification.
